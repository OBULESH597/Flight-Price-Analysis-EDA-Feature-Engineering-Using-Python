# ✈️ Flight Price Analysis — EDA & Feature Engineering Using Python

## 📌 Project Overview

This project focuses on analyzing flight price data using Python to understand the factors and patterns that influence airline ticket prices.

The project includes data cleaning, exploratory data analysis (EDA), feature engineering, statistical analysis, and data visualization. The analysis helps identify relationships between flight prices and factors such as airline, journey date, source, destination, duration, and number of stops.

---

## 🎯 Objectives

- Understand the structure and characteristics of flight price data.
- Perform data cleaning and preprocessing.
- Analyze flight prices using Exploratory Data Analysis.
- Identify patterns based on airlines, routes, stops, and journey dates.
- Create useful features from date, time, and duration columns.
- Visualize important relationships in the dataset.
- Build a Python-based analytical dashboard.
- Prepare the dataset for further machine learning applications.

---

## 📂 Dataset

The dataset contains flight booking information with columns such as:

| Column | Description |
|---|---|
| Airline | Name of the airline |
| Date_of_Journey | Date of the journey |
| Source | Flight departure location |
| Destination | Flight destination |
| Route | Flight route |
| Dep_Time | Departure time |
| Arrival_Time | Arrival time |
| Duration | Flight duration |
| Total_Stops | Number of stops |
| Additional_Info | Additional flight information |
| Price | Flight ticket price |
